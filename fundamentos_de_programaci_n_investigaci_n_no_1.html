Pseudocódigo

¿Qué es y para qué sirve?

El pseudocódigo es una forma informal y de alto nivel de escribir algoritmos en lenguaje humano (como el español) siguiendo una estructura lógica similar a la de un lenguaje de programación formal.

Sirve como una herramienta de diseño previa a la codificación. Permite a los programadores concentrarse en la lógica pura del problema sin preocuparse por las reglas sintácticas estrictas de lenguajes como C++, Java o Python.

Características Principales

  • Independiente: No está atado a ningún lenguaje de programación específico.
  • Estructurado: Utiliza palabras clave estándar (Inicio, Fin, Si-Entonces, Mientras, Leer, Escribir).
  • Legible: Fácil de interpretar por cualquier persona sin formación técnica avanzada.
ejemplo_pseudocodigo.pseint 
Algoritmo PromedioNotas
    // Declaración de variables
    Definir nota1, nota2, promedio Como Real
    
    // Entrada de datos
    Escribir "Ingrese la primera nota:"
    Leer nota1
    Escribir "Ingrese la segunda nota:"
    Leer nota2
    
    // Procesamiento
    promedio <- (nota1 + nota2) / 2
    
    // Condición y Salida
    Si promedio >= 71 Entonces
        Escribir "Estudiante Aprobado con: ", promedio
    Sino
        Escribir "Estudiante Reprobado con: ", promedio
    FinSi
FinAlgoritmo

Diagramas de Flujo

Un diagrama de flujo es la representación gráfica de un algoritmo mediante símbolos geométrica e intencionalmente estandarizados (norma ANSI/ISO). Sirve para esquematizar de forma lógica e intuitiva la secuencia completa de operaciones que ejecuta un sistema.

Símbolos Estandarizados Principales

Inicio / Fin

Óvalo (Terminal)

Indica el punto exacto donde inicia o concluye el algoritmo.

E / S

Paralelogramo

Representa la entrada de datos (teclado) o la salida de resultados (pantalla).

Proceso

Rectángulo

Operaciones matemáticas, asignación de variables o cálculos internos.

¿?

Rombo (Decisión)

Evalúa una condición lógica dividiendo el flujo en ramas Si/No.

Líneas de Flujo

Flechas relacionales que marcan la dirección de la ejecución.

Diagrama Interactivo Paso a Paso

Ejemplo: Validación de Mayoría de Edad

[ INICIO ]
Leer edad
¿edad >= 18?
SI
Escribir "Mayor de edad"
NO
Escribir "Menor de edad"
[ FIN ]

Variables y Constantes

Variables

Una variable es un espacio de almacenamiento nombrado en la memoria RAM del equipo cuyo contenido puede modificarse o cambiar repetidamente durante la ejecución del programa.

Ejemplos típicos:

contador <- 0 // Cambia a 1, 2, 3...

nombreUsuario <- "Miriam"

precioCalculado <- 45.99

Analogía: Una caja donde puedes cambiar el objeto guardado cuando quieras.

Constantes

Una constante es un valor fijo definido al inicio del algoritmo que permanece inalterable durante todo el ciclo de vida de la ejecución del software.

Ejemplos típicos:

PI <- 3.14159265

IMPUESTO_ITBMS <- 0.07

VELOCIDAD_LUZ <- 299792458

Diferencia clave: La constante es de solo lectura una vez asignada.

Tipos de Datos Principales

El tipo de dato define la naturaleza del valor que se puede almacenar en una variable y qué operaciones matemáticas o lógicas es válido realizar sobre ella.

Numérico

Entero

Números completos sin fracciones ni punto decimal.

edad = 25
numEstudiantes = 40
Numérico

Real (Float)

Números cuantitativos que incluyen fracción decimal.

promedio = 4.85
precio = 19.99
Texto

Carácter

Un único símbolo, letra o número entre comillas simples.

seccion = 'A'
genero = 'F'
Texto

Cadena (String)

Secuencia ordenada de múltiples caracteres contiguos.

mensaje = "Hola"
asignatura = "Lógica"
Lógico

Booleano

Tipo binario que solo admite dos valores posibles.

esMayorEdad = Verdadero
activo = Falso

Estructuras Condicionales

Una condición es una expresión lógica que se evalúa devolviendo un resultado Verdadero o Falso. Las estructuras condicionales otorgan la capacidad al programa de tomar decisiones y bifurcar el camino a seguir.

Ejecuta un bloque de instrucciones únicamente si la condición evaluada es verdadera. Si es falsa, ignora el bloque.

Si precio > 100 Entonces
    descuento <- precio * 0.10
FinSi

Presenta dos alternativas: ejecuta un camino si la condición es verdadera y otro distinto si resulta falsa.

Si nota >= 71 Entonces
    Escribir "Aprobado"
Sino
    Escribir "Reprobado"
FinSi

Estructuras condicionales dentro de otras condicionales para evaluar múltiples alternativas en cascada.

Si promedio >= 90 Entonces
    Escribir "Excelente (A)"
Sino
    Si promedio >= 80 Entonces
        Escribir "Bueno (B)"
    Sino
        Escribir "Regular"
    FinSi
FinSi

Ciclos Repetitivos (Bucles)

Los ciclos o bucles ejecutan repetidamente una secuencia de instrucciones mientras o hasta que se cumpla una condición específica. Evitan la duplicación innecesaria de código.

Ciclo Para (For)

Se utiliza cuando se conoce de antemano el número exacto de iteraciones a realizar.

Para i <- 1 Hasta 5 Hacer
    Escribir "Paso: ", i
FinPara

Ciclo Mientras (While)

Evalúa la condición al INICIO. Si es falsa desde el principio, nunca se ejecuta.

Mientras clave != "1234" Hacer
    Leer clave
FinMientras

Ciclo Repetir (Do-While)

Evalúa la condición al FINAL. Garantiza que el código se ejecute al menos una vez.

Repetir
    Leer numero
Hasta Que numero > 0

Tabla Comparativa de Ciclos

Tipo de Ciclo ¿Cuándo evalúa la condición? Mínimo de ejecuciones Uso recomendado

Mientras (While) Al inicio (Pre-evaluación). 0 veces Iteraciones indeterminadas sujetas a eventos.
Repetir (Do-While) Al final (Post-evaluación). 1 vez (Garantizada) Validación obligatoria de menús de usuario.
